# HiDPI 安装教程

适用本机 AUO 屏幕：2560×1600，厂商 ID 6af，产品 ID 7b2。
本包不含 EFI、驱动或修改版 EDID，不适用于其他型号直接套用。

## 前置条件

本机使用 nullmoth NVIDIA 驱动，启动参数需要包含 `nvfbhidpi=1`。
此前已在 U 盘 EFI 中添加该参数并移除 `-v`，请从该 U 盘启动。
本包不会自动修改启动参数。

在终端运行以下命令检查，输出应包含 `nvfbhidpi=1`：

```sh
nvram boot-args
```

## 安装

1. 解压压缩包，将 `HiDPI-Minimal` 文件夹放到桌面。
2. 打开终端，先检查是否已有配置：

```sh
ls -l /Library/Displays/Contents/Resources/Overrides/DisplayVendorID-6af/DisplayProductID-7b2
```

如果已有文件，先运行以下命令备份。备份文件名带时间，不会覆盖旧备份：

```sh
cp /Library/Displays/Contents/Resources/Overrides/DisplayVendorID-6af/DisplayProductID-7b2 "$HOME/Desktop/DisplayProductID-7b2-backup-$(date +%Y%m%d-%H%M%S).plist"
```

3. 运行以下命令安装，按提示输入本机管理员密码（输入时不显示字符）：

```sh
sudo mkdir -p /Library/Displays/Contents/Resources/Overrides/DisplayVendorID-6af
sudo install -o root -g wheel -m 644 "$HOME/Desktop/HiDPI-Minimal/DisplayVendorID-6af/DisplayProductID-7b2" /Library/Displays/Contents/Resources/Overrides/DisplayVendorID-6af/DisplayProductID-7b2
```

本机此前已安装合并版配置，本包使用该配置的副本，无需重复安装。
如现有配置后来有过修改，请先比较内容，不要直接覆盖。

4. 手动重启，从含 `nvfbhidpi=1` 的 EFI 启动。
5. 在“系统设置 → 显示器”或 BetterDisplay 中检查 HiDPI 档位；
   如有“显示所有分辨率”选项，请展开。选择所需档位及 240Hz（若可用）。

## 目标档位

| 界面等效分辨率 | 请求的渲染尺寸 |
| --- | --- |
| 1280×800 | 2560×1600 |
| 1440×900 | 2880×1800 |
| 1600×1000 | 3200×2000 |
| 1920×1200 | 3840×2400 |

本配置不修改原 EDID 或物理时序。目标是高分辨率渲染后缩放到原生面板。
各档能否与 240Hz 同时使用取决于驱动，尚未实机验证成功。

## 检查是否生效

```sh
system_profiler SPDisplaysDataType
```

检查 `UI Looks like` 是否为选择的界面分辨率，刷新率是否为 240Hz。
普通低分辨率模式不等于 HiDPI；同样的分辨率名称可能对应不同渲染尺寸。
如果仍缺少档位，先确认启动参数已生效，不要继续伪造 EDID。

## 恢复

如果安装前有配置，使用桌面上对应的备份恢复到原路径，然后重启。
如果安装前没有配置，只删除本包安装的文件，然后重启：

```sh
sudo rm /Library/Displays/Contents/Resources/Overrides/DisplayVendorID-6af/DisplayProductID-7b2
```

不要删除整个 Overrides 文件夹。
测试前应准备外接显示器或安全模式恢复途径。

## 注意

`DisplayProductID-7b2` 是 macOS 显示覆盖 plist，不是 EDID 二进制。
不要在 BetterDisplay 的“加载 EDID 数据”中导入，不要写入屏幕 EEPROM。
本包不需要修改 EFI、关闭 SIP 或写入 /System。
启动参数前置要求仍需满足。
